A tiny Python program that writes one painfully honest but still polite out-of-office email auto-reply, 154 characters in a single sentence, to /output/entry.txt for make.fun's The Painfully Honest Out-of-Office bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
